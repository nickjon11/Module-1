Linux Basic Commands:
pwd    : current directory
ls     : list files in directory
ls -la : files with detail
cd     : change directory
mkdir  : create new directory
rmdir  : delete directory
touch  : create new file
cp     : Copy Files
rm     : Delete File
nano   : edit a file in nano
vi     : edit a file in vi
clear  : clear terminal screen

Git Basic Commands:
git init       : initalize a Git repository
git clone      : Clone a repository             : git clone <url>
git status     : Show Repository Status
git add        : Stage change
git commit -m  : Commit Staged changed          : git commit -m "filename"
git log        : Commit history
git branch     : List Branches
git pull       : Download changes from remote   : git pull origin main
git push       : Upload changes to remote       : git push origin main
git rm         : Remove a tracked file          : git rm file.txt
